# Minimax H3 全能视频节点

接入日期：2026-10-16。名称：🦁Minimax-H3全能视频@炮老师的小课堂。
分组：🤖dapaoAPI/🍬大炮AI主力维护🍬。

## 使用

重启ComfyUI并刷新网页，搜索Minimax-H3。密钥可填写，或留空使用DAPAO_API_KEY。
不连接素材为文生视频，连接图片为图生视频，可同时连接参考视频和音频；不提供未经文档支持的首尾帧角色。
输出视频接ComfyUI“保存视频”，另有任务ID、响应信息、视频URL输出。节点完成前已将成片保存到ComfyUI输出目录下的dapao_h3；响应信息包含本地路径。

- 唯一模型：minimax-h3-miaobi；不会切到MiniMax-H3官方通道。
- 720P/1080P；默认720P、4秒，允许3至15秒整数；比例16:9或9:16。
- 最多9张图片、3段视频、3段音频，混合合计12项。每个IMAGE批次逐张计数，超限明确拒绝，全部校验和预处理成功后才上传/提交。
- 音频必须搭配图片或视频；声音开关默认开启，显式关闭会发送false。
- 图片每张独立缩放到最长边≤2048，PNG上传；单张≤10MiB。共享音视频预处理输出MP4/H264/AAC和MP3，不修改源文件；按接入建议限制每段2–15秒、每类总时长≤15秒。视频使用现有预处理的≤1080最长边、30fps和体积预算；这是客户端预处理策略，不宣称是H3全部原生限制。
- 价格由ComfyUI后端只读获取公开价格表，前端显示标准分组每秒价格与预计费用。不执行远端计费表达式；只解析文档对应的已知结构，结构改变或读取失败则显示费用以账单为准。未查询个人分组，不将标准价当个人结算价。当前读取720P为0.075元/秒、1080P为0.135元/秒。
- 随机种只用于ComfyUI缓存与持久队列恢复，不发给模型；默认fixed。要生成一份新视频，改变随机种或将生成后控制设为randomize。

## 恢复与安全

POST /v1/videos使用共享持久队列的Prefer: respond-async和Idempotency-Key；不自动重试付费POST。队列成功后读取提交结果id，再GET /v1/videos/{id}查询，completed才下载。

“继续任务ID”可填写job_队列ID或视频任务ID；此模式跳过提示词、素材上传和生成POST，只查询并保存，优先用于断线、超时、保存失败后的恢复。停止客户端等待不宣称取消上游或退款。不自动切模型。

共享数据库保存原幂等键、请求hash、队列状态与受理结果；额外任务记录位于ComfyUI用户目录dapaoAPI/h3_tasks，保存请求JSON、恢复随机种、队列ID、视频ID及本地文件路径，账号只保存hash，不保存密钥。该记录可能包含用户提示词，属本地任务数据，不用于日志或项目导出。服务端记录和素材有有效期，不能保证任意时间后恢复；已有任务优先使用ID，不重新上传。

外部直链下载不带妙笔密钥；失败回退到固定api.dapaoai.com/v1/videos/{id}/content，禁止带密钥跟随重定向。流式写临时文件，ffprobe确认视频及实际宽高后原子改名；保存失败保留ID供重试。FFmpeg/ffprobe需要可用，可设置DAPAO_FFMPEG_PATH、DAPAO_FFPROBE_PATH。
