# 👩‍🦱超写实人物提示词@炮老师的小课堂

位置：`🤖dapaoAPI/🍬大炮API常用工具🍬`。重启 ComfyUI 并刷新网页后可搜索“超写实人物”。

填写 API 密钥、选择项目统一 LLM，输入人像需求即可运行。未填需求时按技能默认审美规划。
默认折叠摄影参数，展开后可选择完整场景池、动作池、年龄、人物、地域、景别、机位、
前景、配色、光线、主辅光学效果、情绪、发型、服装和民俗文化风格。自定义内容填入补充约束。

| 模式 | 用途 | 图片输入 |
| --- | --- | --- |
| A | 保留身份、表情、动作、服装，升级普通照片的摄影表现 | 原照片必需 |
| B | 原创生命感样片，成组规划人物、事件、镜头与光色差异 | 无图可用，参考图可选 |
| C | 保留人物及原场景事件，增强氛围、景深、光线和色温关系 | 原照片必需 |

自动模式有原照片选 A，仅有风格参考图或无图选 B。风格图仅提取摄影语言。
两类输入各最多 6 张，超限明确报错；每张独立用共享工具处理为最长边不超过 2048 的 PNG。
A/C 原图批次有多张时，方案数至少等于原图数量，完整方案 JSON 中的 `source_image_index`
标明从 1 开始的原照片编号。下游编辑节点请连接对应原图；本节点不自动传出或重新排列图像。

前两个输出是选中方案的正向、负面提示词，可直接连接生图节点。
两个批量输出是相同顺序的 STRING 列表，适合下游 ComfyUI 列表映射。
其余输出是完整拍摄方案 JSON、参考图分析、提示词质检、LLM 原始文本和处理信息。
质检是 LLM 对提示词规划的自检，不能保证尚未生成的成品效果。

方案数量为一次 LLM 请求规划 1–12 条提示词，与上游列表并发独立。
本节点公开方法为异步方法，每个任务有独立客户端，沿用项目队列和幂等恢复机制。
付费提交不自动重试。默认出错抛异常；开启“出错时跳过”时提示词为空、批量输出为空列表，
错误保留在质检与处理信息输出，避免错误文字被下游当作提示词付费出图。
多方案或中英双份输出被截断时，可提高最大输出令牌或减少方案数量。
仅收取所选 LLM 的实际用量费用，以平台账单为准；本节点不调用生图接口。
