# 🐠漫剧一站式专用🐠

分组：`🤖dapaoAPI/🐠漫剧一站式专用🐠`，位于“大炮API常用工具”后面。主菜单现在只保留3个合并节点；原11节点放在“🧰高级分步（原11节点）”子菜单，旧工作流继续兼容。
只调用妙笔工坊的LLM文本接口；不调用图片、视频、音乐、TTS模型，不安装生产adapter，不启动原项目Dashboard。

## 推荐：三节点简化流程

03支持“时长规划→手动逐段时长”，例如`6,6,8,10`要求4段、共30秒，手动总计优先于01原目标时长。按原剧情重新规划镜头而非裁掉成稿；每段须符合01已设置的单镜最短/最长秒数。输入错误在调用前拒绝，模型未遵守逐段时长则停止后续阶段，不自动重试。“仅视频”要求已有分镜符合计划，否则请先重做分镜；“仅整理/仅审查”不修改现有时长。

03追加“全部视频时长列表”（对应完整视频提示词列表）、“所选批量时长列表”（对应所选关键帧/视频提示词），单位秒、FLOAT列表，支持小数秒。筛选序号和顺序完全一致；选择资产图片时所选时长为空。接下游时须同时使用配对的提示词与时长列表；若视频节点只接受INT，需先用数值转换节点逐项转换整数秒，若是固定下拉档位则按模型支持档位分别执行。不能把全量时长接到筛选后的提示词上。实际视频生成费用取决于下游模型、分辨率与计费方式，这里控制的是计划数量和时长。

02的“资产规划”默认人物优先，先角色设定再必要场景；普通门、门铃等环境构件并入场景。也可选择“仅人物设定”或“完整资产（人物＋场景＋关键道具）”。改变此选项会改变生成请求，可能产生新的LLM费用。

接到Easy-Use“展示任何”的漫剧列表采用唯一名称的逐条文本框预览，每条只含原提示词，不添加编号、不拼接。后台是与电商详情页“所选分屏批量提示词”相同的列表输出。真实相同的资产提示词正文会触发重复检查，不静默删除或用重复内容凑数。

直接将02的“所选资产批量提示词”或03的“所选批量提示词”连接图片节点的提示词输入，即可逐条映射执行。03先选择批量输出内容；“提示词选择”留空为全部，也可填写`1,3-5`或完整条目ID。无需先经过展示节点或手动拆分文本。原三个完整列表出口保留。选择的是提示词条目，每条实际出图数量仍由图片节点控制。

三个节点新增独立任务选项，可只分析原著/只开发系列/只修订剧本、复用视觉设定只写图片提示词、复用分镜只写视频提示词、只做文本审查。点击“展开高级功能”选择专项参考、导入文档或填各阶段修订稿。图片用途提供身份板、三视图、变体、地点、道具、组合板、Lookdev、局部编辑。详细对应关系见[原技能功能对照](short_drama_capability_audit.md)。

拖入 `example_workflows/漫剧_00_三节点简化流程.json`，三个节点已经连好：

**01 漫剧剧本准备 → 02 漫剧人物与画面 → 03 漫剧分镜与交付**

1. 在01粘贴“剧本或故事内容”，按内容选择“已有剧本 / 原创想法 / 小说改编”。填写时长、风格、画幅；模型和随机种等先用默认值。已有剧本会保留剧情并规范化；小说会先分段分析再规划和写作，不截断全文。当前按一集处理，长篇剧本请按集提供。
2. 在02选“人物场景分析＋资产图片提示词”，自动完成角色、场景、道具及对应图片提示词。如果只需要视觉分析，可选择“仅人物场景分析”。
3. 在03保留“自动（按制作形态）”，会生成分镜关键帧；动态形态继续生成视频提示词，静态漫剧跳过视频。文本审查默认关闭，需要时开启。
4. 三个节点填写同一API密钥，或统一通过 `DAPAO_API_KEY` 环境变量读取。运行后直接在节点中看文档预览，在03点击“下载提示词清单JSON”。三类提示词列表可分别接到后续生成节点，本套组不生成图片或视频。

只需连接两个“漫剧资料包 → 上游资料”，不用手动合流。每个合并节点都能单独执行并预览，因此也可以先只添加01确认剧本，满意后再添加02、03。“本阶段要求”作用于该合并节点内的阶段；如果需要只修订一个细分阶段，可以用高级分步节点。

03还可选“仅整理已有提示词（不调用LLM）”，直接整理连接的资料包，不生成分镜、不调用审查；但它不会阻止工作流中尚未执行的上游节点调用LLM。需要保留所有原有结果时用此模式。

费用按内部阶段计算，不是每个合并节点只请求一次。已有剧本默认整条链为5次LLM响应（剧本1、视觉2、分镜视频2）；静态为4次，审查另加1次。小说分段和系列规划会增加调用。相同请求与固定种在恢复期内可复用成功结果，响应次数不等于新增扣费次数。出错不自动重试；格式检查失败时保留草稿预览并停止后续调用，需修订后再运行。

更新后重启ComfyUI并Ctrl+F5刷新。新例子不包含API密钥，原示例仍使用高级分步节点。

连接每个节点的第一个「漫剧资料包」输出到下一个节点的「上游资料」。图片与分镜可以分支，也可以
串接 `05 → 06 → 07 → 08 → 10`；串接时分镜能直接引用已写好的IMG身份板。示例工作流采用串接，

现成单集剧本：在01选择「已有文档类型=剧本.md」并粘贴正文，直接接05，不必跑02、03、04。
现成视觉设定：06可以单独接「视觉设定.md」文本。现成分镜：08需要同时提供剧本、视觉设定、分镜文本。
所有LLM阶段支持「原文或现有稿」和「本阶段要求」，可修订已有稿。直接输入的文档会覆盖资料包内同类文档；
它的下游旧版本因此会被标记过期。请从需要修订的阶段重新运行后续节点，不会自动付费重写。

每个分支深拷贝输入，不修改兄弟支线。来源文档指纹只用于本地版本检查，不发给图片或视频模型。

## 参考图片与视频方言

默认选择「挂图计划（自行出图）」。`IMG-*` 表示图片提示词，`SHOT-*`表示关键帧提示词，
`PLAN-*`表示未来在你自己的生成工具里挂载哪张图、顺序、用途、控制范围。它们都不代表真实图片已经存在。
本套组没有实际图片输入，因此不创建、验证或接受声称已核验像素的`REF-*`引用。

只有项目入口明确选择「明确文生视频」时，才使用无需参考图的自足视频提示词。
模型方言仅影响提示词写法，当前LLM仍由统一模型下拉选择。方言资料来自这次内置的原技能快照，
不是服务商当前模型能力保证；「单镜最短/最长秒数」由使用者按实际生成工具填写，0表示未限定。
连续视频续接需要实际上一段视频与尾帧；这里只能输出说明或草案，不能声称已经取得续接素材。

## 长篇原著

02需要实际正文，不能只输入书名。支持当前材料单次分析、抽样快评、全文分段分析。
分段使用原项目章节索引算法识别章/回/节、目录与卷重启；有明显跳号、重复或空章时在请求前提示检查。
无章节标题时按设置字符数切片；也可以明确选择「按字符分段」。超长单章继续切为有确定字符位置的小片段。
每段的来源位置、覆盖率和提取依据会保留。抽样会明确报告未覆盖范围，不把快评冒充全书分析。

全文超过「最大分析段数」时在付费前停止。每段一次LLM请求，另加汇总；若提取内容超出上下文，
会逐级汇总并报告实际响应次数。中间成功响应通过共享持久队列保存；同输入与随机种在恢复期内复用，
失败不会自动重试。正文不静默截断，输出截断也会明确报错。
长篇分析的逐段提取保留在分析文档附录，开发阶段使用汇总结论，不反复把整个原著或全部提取塞进上下文。

## 规范与费用

8个LLM节点均引用`llm_model_options.py`，默认和候选列表跟随项目统一更新，前端不复制硬编码模型表。
实际请求复用`dreambrush_runtime.submit_json_task`，地址为`https://api.dapaoai.com/v1/chat/completions`。
公开执行方法异步，由ComfyUI将上游列表映射为可重叠的独立任务；节点不使用`INPUT_IS_LIST`抢接整条列表。

默认随机种控制为固定。相同内容、设置、种在48小时恢复期内复用成功LLM响应；修改内容或种会成为新请求。
「响应次数」包含复用结果，不等于实际扣费次数。单节点长篇内部多次调用与上游列表并发是两件事。
价格标签只提示实际LLM用量计费，具体金额看平台账单。不提交图片、视频或音频任务。

API密钥可在每个LLM节点填写，也可在启动ComfyUI前设置`DAPAO_API_KEY`并让输入框留空。
节点输出与异常会遮蔽当前密钥、Bearer值和常见sk密钥；普通工作流本身仍可能保存用户填写的明文字符串。
资料包不携带鉴权信息。11个节点均提供随节点宽度重绘的注册按钮，兼容pointerdown/mousedown/click。

## 检查与限制

全集连续性锁未在每条提示词中逐字出现时，会列为人工复核提示，不再据此阻断局部特写和交付；显式指定镜头/图片的锁仍执行严格检查。文字缺失不能直接证明人物或场景发生矛盾，实际一致性仍需结合提示词、参考图与生成结果判断。合并节点遇到结构错误会停止后续调用，但保留已通过检查的提示词列表，交付检查明确标注“部分交付”。

本地检查包括条目ID、场景覆盖、视觉依据、IMG/PLAN引用、可复制块、视频与分镜一一对应、时长、
挂图声明、连续性锁和文档版本。结构失败时仍返回原LLM文档与问题信息，让你能查看和修订；后续节点阻止使用坏稿，
不会自动付费“修复”。09负责进一步语义审查，但不能保证情节质量、人物一致性或尚未生成媒体的效果。

测试以模拟LLM响应完成整条链、分支合流、静态交付、长篇覆盖、脱敏、失败不重试与列表并发；没有真实付费调用。
运行：`python -m unittest test_short_drama_nodes -q`；前端：`node test_short_drama_ui.cjs`。

### 妙笔接口连接与断线恢复

默认 `api.dapaoai.com` 的共享素材/队列请求直接连接，避免继承桌面代理导致不必要的转发。其他域名不变；确需走系统代理时，在启动 ComfyUI 前设置 `DAPAO_DREAMBRUSH_USE_SYSTEM_PROXY=1`。不会修改系统代理或自动重试付费 POST。

已取得 Job ID 后的查询断线保留原任务；固定输入与随机种恢复时只查询该 Job。未取得 Job ID 的提交回包中断保留幂等键，但不能据此保证服务端已受理或未扣费。

### DeepSeek V4 文档生成

漫剧阶段对 deepseek-v4-flash / deepseek-v4-pro 显式发送 thinking.type=disabled，避免内部思考耗尽 max_tokens 后无正文。其他模型参数保持不变，不使用 reasoning_content 冒充交付提示词。依据：https://api-docs.deepseek.com/guides/thinking_mode/ 。已用用户当前剧本与视觉设定通过妙笔持久队列真实验证图片提示词阶段：3条提示词、1319字符、结构检查通过。

### 刷新后节点尺寸（2026-09-08修订）

文本框的旧版computeSize和新版computeLayoutSize均使用固定布局高度；长文本在框内滚动。新建节点在隐藏高级参数、未启用的分段参数后计算初始高度，不再保留构造过程中全部控件形成的超长尺寸。旧工作流首次载入时，对超过紧凑高度600像素的旧尺寸做一次修复；之后保留用户保存的尺寸。

更新后强制刷新浏览器（Ctrl+F5），调整布局后保存工作流（Ctrl+S）。刷新恢复的是已保存的工作流。真实前端已验证：保存540×950后连续刷新3次仍为540×950，高级功能展开/收起保持宽度。

### 完整资料包的固定输出口
