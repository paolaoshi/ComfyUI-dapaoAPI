# 漫剧三节点与原技能功能对照

核对来源：用户提供的“漫剧一站技能包skills”十份SKILL、对应参考目录，以及“原项目”的README和creator-first工作流。原技能正文及参考仍内置，不把技能压缩成几个通用提示句。

## 批量输出修正

电商详情页节点把`selected_prompts: list[str]`直接作为输出，并将对应`OUTPUT_IS_LIST`设为True。漫剧采用相同方式：

- 02第四个出口：所选资产批量提示词。
- 03原来的资产、关键帧、视频三个列表出口保留；第八个出口：所选批量提示词。
- 条目选择留空为全部；支持`1,3-5`或完整条目ID。只筛选批量出口，不截断创作文档，不删除挂图引用。
- 每个元素保持一条完整提示词，包括其内部换行；没有序号、分隔线、JSON包装或合并正文。
- 直接接图片/视频节点的提示词输入，由ComfyUI逐项映射。展示任何只是旁路预览，不需要串在生成链里。
- Easy-Use预览使用唯一名称的逐条文本控件，避免多个`text`控件串值。预览值保持原文，后台输出不变。

使用本机ComfyUI的`merge_result_data`及`_async_map_node_over_list`做离线验证：三条不同提示词传到三个同时等待的模拟图片任务；三条全部进入后才允许返回。没有提交媒体API请求。

## 三节点内可达的技能功能

| 原技能 | 三节点入口 | 保留内容 |
|---|---|---|
| short-drama | 01项目设置、导入文档、上游资料包；03本地交付 | 单集五文档、制作形态、语言、画幅、模型方言、挂图计划、已有文档直接进入后续阶段 |
| novel-analyze | 01准备任务→仅原著分析；高级功能→分析方式 | 当前材料、抽样、全文分段，原章节索引、覆盖率、分段上限、成功请求恢复；分析后可停下 |
| develop | 01→仅系列开发，或系列规划 | 创作简报、改编边界、导演方向、故事引擎、分集地图；可接已有分析或系列稿 |
| write | 01→仅剧本创作或修订 | 原稿规范化、定点修订、剧情/对白/声音/连续性；可复用上游资料，不强制重做分析 |
| assets | 02→仅人物场景分析 | 人物、造型、身份与变体、地点、道具、声音方向、连续性状态；可提交视觉设定修订稿 |
| image-prompts | 02→仅资产图片提示词 | 不重拆已有视觉设定；身份板、三视图、状态变体、地点、道具、组合板、Lookdev、局部编辑；对应用途自动加载专项配方 |
| storyboard | 03→仅分镜关键帧 | 剧本来源、镜头职责、动作起终、时长、空间连续性、关键帧、IMG/PLAN引用；可定点修订及选读调度/覆盖等参考 |
| video-prompts | 03→仅视频提示词 | 复用已有分镜，不强制重做；方言、动作、运镜、表演、对白与声音时间线；音乐要求可写入视频文档独立章节 |
| review | 03→仅文本审查，或明确开启附加审查 | 原著、剧本、资产、图片、分镜、视频、隐私、反模板等范围；输出证据、影响与负责修订阶段，不自动改稿 |
| produce | 03→仅整理已有提示词 | 本次用户授权范围内适配为提示词选择、批量输出、清单、文档预览与JSON下载，不接入媒体生产 |

每个LLM阶段都保留自己的技能加载与校验，合并只负责顺序和资料传递。高级功能可展开各阶段的专项参考及修订稿，支持自动精选、单份参考、全部阶段参考。文档导入按类型保存；已有资料包可继续使用，导入修改会触发下游版本检查。主界面仍为三个节点。

## 明确的适配范围

用户要求的是提示词生成部分。原项目的Dashboard、CLI发布/审批、供应商adapter、真实图片/视频生成、TTS、音乐生产、成品媒体审查不在这套节点里。PLAN是挂图计划，不冒充已核验的REF媒体。真实续接视频与尾帧尚未提供时，不能声称可以自动完成续接生产。

当前按当前集号处理一集，系列开发可以生成分集地图，但不把多集整稿自动变成整季付费生产任务。时间线音乐文字保存在视频文档中，不作为图片或视频批量元素。更换任务/用途/参考或修订要求会改变LLM请求，可能新增费用；单纯选择导出的提示词使用本地处理，工作流上游未缓存时仍可能运行。
